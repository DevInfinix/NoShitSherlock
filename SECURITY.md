# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of NoShitSherlock seriously. If you discover a security vulnerability, please do NOT disclose it publicly in an issue or discussion.

### How to Report

Please report security issues privately by emailing the maintainers or creating a private security advisory on GitHub:

- **Email**: `admin@thesamstudios.in`
- **GitHub**: Use the "Report a repository vulnerability" button under the **Security** tab.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any suggested remediations if available.

### Response Timeline

- **Initial Response**: Within 48 hours of receipt.
- **Status Updates**: Periodic updates regarding triage and patching progress.
- **Public Disclosure**: Coordinated after a fix has been developed and deployed to production.
